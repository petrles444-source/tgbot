# Telegram-боты: Ада, Анатолий, Effy

Три бота на чистом Python. Живут на PythonAnywhere, спрашивают у
человека, отвечают по характеру, который настраивается прямо в чате.

| Кто | @username | Токен в переменной |
|---|---|---|
| Ада | `@adaweffeBot` | `ADA_TOKEN` |
| Анатолий | `@social_neuro_bot` | `ANATOLY_TOKEN` |
| Effy | `@social_neuro2_bot` | `Social_TOKEN` |

> **Имена.** Подписи в Telegram совпадают с именами в коде: Ада,
> Анатолий и Effy. Раньше `ADA_TOKEN` вёл на бота, подписанного
> «Анатолий», и путаница была настоящей: два бота с одним именем
> отвечали на зовут одного и того же человека.

Роли различаются, хотя имена теперь не пересекаются: Ада —
помощница в чате, Анатолий — по программированию, Effy — по
текстам.

## Запуск

Подробная инструкция с таблицей симптомов — в
[`bots/ЗАПУСК.md`](bots/ЗАПУСК.md). Коротко:

**На сервере:** https://www.pythonanywhere.com/consoles/ → ссылка
**Bash** → в поле скрипта `bash /home/HostMoon6/bots/запустить.sh`
→ галочка. Консоль создастся и сразу запустит ботов.

**На своём компьютере:** двойной щелчок по
[`bots/запустить-локально.bat`](bots/запустить-локально.bat).

## Ключи

Живут в `bots/секреты/`, в git не попадают.

```
bots/секреты/ключи-ботов.local.json      три токена Telegram
bots/секреты/ключи-моделей.local.json    ключ модели
```

Заполнить образец — `bots/код/config.example.json`.

**Токены не должны попадать в репозиторий.** Репозиторий публичный,
а файл в истории git остаётся навсегда: удаление из последнего
коммита не убирает его из прошлого. Токен, попавший в историю,
считается скомпрометированным — его отзывают только перевыпуском
у @BotFather.

## Модели

Пять моделей, переключение прямо в чате:

```
/модели          список
/модель 2        переключить по номеру
/модель быстро   переключить по названию
```

| # | модель | провайдер | скорость |
|---|---|---|---|
| 1 | `qwen/qwen3.8-27b` | Groq | 0,2–0,3 с |
| 2 | `openai/gpt-oss-120b` | Groq | 0,6–16 с |
| 3 | `nvidia/nemotron-3-super-120b-a12b:free` | OpenRouter | 0,7–2,5 с |
| 4 | `inclusionai/ling-3.1-flash` | OpenRouter | 1,6–3 с |
| 5 | `liquid/lfm-2.5-2.6b:free` | OpenRouter | ответит не всегда |

Если модель не ответила, бот молча берёт следующую и человек
видит просто ответ — без «провайдер ответил HTTP 403». Ключи
ротируются: у Groq их восемь, и лимит считается на ключ.

## Что боты умеют кодом, без нейросети

* отклик на имя — 35 вариантов написания, любой регистр;
* **молчание** на «адаптер», «палата», «толяк», «кетоны», «катька»;
* приветствия — пять вариантов, без повторов подряд;
* арифметика, время, длина текста;
* команды настройки характера: `/характер`, `/char`, `/режим`,
  `/характер сброс`;
* выбор модели: `/модели`, `/модель 2`.

Свободный разговор — только через нейросеть.

## Ограничения тарифа PythonAnywhere

* **Одна консоль.** Три процесса не запустить — памяти не хватиет.
  Поэтому `run_all.py` поднимает трёх ботов одним процессом.
* **Ключ API не управляет консолью.** `POST` на консоль отвечает
  405, `scheduledtasks/` — 404. Запускать руками в браузере.
* **Боты живут, пока открыта консоль.** Фоновые задачи по API
  недоступны, а `wsgi.py` на бесплатном тарифе не заводится.
* **CPU:** 100 секунд в день. Боты, которые просто ждут сообщений,
  едят почти ничего.

Рабочий API — **v0**, с именем пользователя в пути:
`https://www.pythonanywhere.com/api/v0/user/HostMoon6/`. Версии `v2`
не существует. Из `v0` работают только `cpu/`, `consoles/`,
`webapps/`.
