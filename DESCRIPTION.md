# Описание проекта

Репозиторий содержит три разговорных Telegram-бота на Python: Аду — помощницу для общения, Анатолия — помощника по программированию и Effy — помощницу по текстам. Боты поддерживают настройку характера командами в чате, переключение языковых моделей и запуск локально или на PythonAnywhere.

Подробности, команды и инструкции по запуску — в [README.md](README.md).
