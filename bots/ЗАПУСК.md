# Как запустить ботов — инструкция на будущее

Три бота: **Ада** (@adaweffeBot), **Анатолий** (@social_neuro_bot),
**Кети** (@social_neuro2_bot).

Всё нужное лежит в одной папке проекта: `WelcomeScreen/zagent/bots/`.

---

## Коротко: одна команда

Открыть консоль PythonAnywhere и вставить:

```
bash /home/HostMoon6/bots/запустить.sh
```

Всё. Токены подставляются сами, из файла на сервере.

**Консоль:** https://www.pythonanywhere.com/consoles/

Если консоли нет — создать: **Consoles → Create a new console**,
затем снова вставить команду.

---

## Что делать, если боты молчат

| Симптом | Причина | Что делать |
|---|---|---|
| `НЕТ ФАЙЛА КЛЮЧЕЙ` | не залиты токены | `python tmp/upload_bots_secret.py` с компьютера |
| `ModuleNotFoundError: ada_bot` | не тот каталог | `cd /home/HostMoon6/bots && ls` — должен быть `run_all.py` |
| `Нет файла run_all.py` | код не залит | `python tmp/start_bots_pa.py` с компьютера |
| боты не отвечают, в логе тишина | процесс упал | смотреть лог в консоли, запустить заново |
| `HTTP 403 от провайдера` | ключ модели мёртв | см. раздел ниже |

## Перезапуск после правок

**Закрыл окно консоли — боты остановились.** Это не сбой,
так и устроено: боты живут в процессе консоли.

Перезапуск — снова одна команда:

```
bash /home/HostMoon6/bots/запустить.sh
```

### Что требует перезапуска

| Изменил | Перезапуск | Почему |
|---|---|---|
| `bots/код/ada_bot.py` | **да** | код читается при старте |
| `bots/код/chars.py` | **да** | тот же файл |
| `bots/config.json` | **да** | читается при старте |
| тексты персон в `character/` | **нет** | команда `/setjailbreak` в Telegram перечитывает их сама |
| ключи в `секреты/` | **да** | заливаются заново на сервер |

Правку в текстах персон можно делать, не трогая консоль: боится
только сервер — файлы на сервере не меняются сами, их нужно
залить заново, а потом вызвать `/setjailbreak`.

## Как править на компьютере и выкладывать

Всё, что делается с кодом бота, идёт через две команды с
компьютера. В консоли сервера файлы править нельзя: при
следующей выкладке правки пропадут.

```powershell
cd C:\Users\HP\PycharmProjects\WelcomeScreen\zagent

# 1. Проверить, что вообще можно на сервере
.\.venv\Scripts\python.exe hosting\pythonanywhere\deploy.py --check

# 2. Залить обновления
.\.venv\Scripts\python.exe tmp\start_bots_pa.py
```

После заливки — снова `bash /home/HostMoon6/bots/запустить.sh`
в консоли.

### На своём компьютере

Проще всего: двойной щелчок по `bots\запустить-локально.bat`.
Окно можно свернуть, закрывать нельзя.

Вручную:

```powershell
cd C:\Users\HP\PycharmProjects\WelcomeScreen\zagent
.\.venv\Scripts\python.exe bots\код\run_all.py
```

Токены подхватываются из `bots\секреты\ключи-ботов.local.json`.

## Про ключ модели

Ответ «Не получилось ответить: провайдер ответил HTTP 403» —
это **не поломка бота**. Ключ модели мёртв, поэтому нейросетевые
ответы не работают.

Что работает **всегда, кодом, без нейросети**:

* отклик на имя: Ада, ада, АДА, Толя, Толян, Катя, катюх, Кет;
* молчание на «палата», «толяк», «кетоны»;
* приветствия и прощания;
* команды настройки характера.

Что не работает без ключа: свободный разговор, арифметика,
длина текста, время.

**Арифметика уходит в нейросеть**, хотя можно было бы посчитать
кодом — на будущее стоит знать.

Ключ меняется в `bots/секреты/ключи-моделей.local.json`, потом:

```powershell
.\.venv\Scripts\python.exe tmp\upload_bots_secret.py
```

## Ограничения тарифа

* **Одна консоль.** Три процесса не запустить — памяти не
  хватит. Поэтому `run_all.py` поднимает трёх ботов одним
  процессом с тремя потоками.
* **Ключ API не управляет консолью.** Отправка команды по ключу
  отвечает 405. Запускать — руками в браузере.
* **Фоновые задачи недоступны по API.** Боты живут только пока
  открыта консоль. Планировался «вечный» запуск через
  веб-приложение, но `wsgi.py` на сервере не заводится.

---

## Чего делать нельзя

* **Писать ключи в код или в репозиторий.** Токен в истории git
  остаётся навсегда: его отзывут только перевыпуском у
  @BotFather.
* **Писать ключи в команды консоли.** Они останутся в истории.
  Скрипт `запустить.sh` существует именно ради этого.
* **Править файлы прямо на сервере.** При выкладке пропадёт.
* **Править `bots/код/`, пока боты работают.** Закрой консоль
  сначала.
