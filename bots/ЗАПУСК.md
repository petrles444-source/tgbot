## Перезапуск после правок

**Закрыл окно консоли — боты остановились.** Это не сбой,
так и устроено: боты живут в процессе консоли.

Перезапуск — снова одна команда:

```
bash /home/Mamont65/bots/запустить.sh
```

### Что требует перезапуска

| Изменил | Перезапуск | Почему |
|---|---|---|
| `bots/код/ada_bot.py` | **да** | код читается при старте |
| `bots/код/chars.py` | **да** | тот же файл |
| `bots/код/modelswitch.py` | **да** | тот же файл |
| `bots/config.json` | **да** | читается при старте |
| тексты персон в `character/` | **нет** | команда `/setjailbreak` в Telegram перечитывает их сама |
| ключи в `секреты/` | **да** | заливаются заново на сервер |

Правку в текстах персон можно делать, не трогая консоль: боится
только сервер — файлы на сервере не меняются сами, их нужно
залить заново, а потом вызвать `/setjailbreak`.

## Как править на компьютере и выкладывать

Всё, что делается с кодом бота, идёт через две команды с
компьютера. В консоли сервера файлы править нельзя: при
следующей выкладке правки пропадут.

```powershell
cd C:\Users\HP\PycharmProjects\WelcomeScreen\zagent

# 1. Проверить, что вообще можно на сервере
.\.venv\Scripts\python.exe hosting\pythonanywhere\deploy.py --check

# 2. Залить обновления
.\.venv\Scripts\python.exe tmp\start_bots_pa.py
```

После заливки — снова `bash /home/Mamont65/bots/запустить.sh`
в консоли.

### На своём компьютере

Проще всего: двойной щелчок по `bots\запустить-локально.bat`.
Окно можно свернуть, закрывать нельзя.

Вручную:

```powershell
cd C:\Users\HP\PycharmProjects\WelcomeScreen\zagent
.\.venv\Scripts\python.exe bots\код\run_all.py
```

Токены подхватываются из `bots\секреты\ключи-ботов.local.json`.

## База знаний: ответы из файлов, а не из головы модели

Модель не знает ничего об этом проекте и про вас лично. На вопрос
«какой у тебя контекст» она уверенно называет цифру, которой в
проекте нет, и человек ей верит.

База знаний — это папка `bots/знания/`. Перед разговором бот ищет
по ней обычными словами и кладёт в запрос только то, что относится к
вопросу: два-три абзаца, не больше. Ответ взятый из файла правдив по
построению — он написан здесь и отсюда же прочитан.

### Как наполнить

Положите в `bots/знания/` обычный текстовый файл `.md`:

```markdown
# Мой проект

## Что это

Короткое описание — бот найдёт файл по слову «проект».

## Как запустить

Точные шаги. Это бот расскажет слово в слово.
```

Правил три, и все простые:

* первая строка с `#` — название, по нему файл ищется;
* подзаголовки `##` — то, по чему бот выбирает нужный кусок;
* больше 40 КБ на файл класть не надо: файл читается целиком.

Перезапускать после этого ничего не нужно: бот сам видит, что файл
поменялся, и пересобирает поиск.

> Замер: `liquid/lfm-2.5-2.6b` через OpenRouter, 6 замеров
> вперемешку с базой и без неё. Медиана 1687 и 1468 мс — разница
> меньше разброса самих замеров (990 мс). Первый, неверный замер
> показал +1,6 с: он мерил сначала без базы, потом с базой, и разницу
> съела разная нагрузка на шлюб.

### Сколько это стоит по времени

Замер на живой модели, тем же вопросом, что с базой и без неё,
замеры вперемешку: **разницы нет**. Поиск — 0,3 мс на вопрос,
повторный вопрос берётся из кэша почти мгновенно, а сам запрос к
модели — от 200 до 1700 мс. Помещается туда вся база.

Если всё же покажется, что ответы стали медленнее, база
выключается одним ключом в `bots/config.json`:

```json
"knowledge": {"enabled": false}
```

Код трогать не надо. В `config.json` ключ уже стоит — там же
написано, что это.

### Чего база не делает

Не ищет по смыслу, а только по словам: «память» найдёт раздел про
память, но «что ты помнишь» может и не найти. Не читает интернет и
не выходит за пределы своей папки. Не заменяет модель: база — на
точные вопросы, модель — на всё остальное.

## Про модель

Сообщение «Не получилось ответить: провайдер ответил HTTP 403»
в чате больше **не появляется**. Если модель не ответила, бот
молча берёт запасную, и человек видит просто ответ. Если не
ответила ни одна — в чат идёт «сейчас не получается ответить,
попробуй через минуту», без технических подробностей.

### Пять моделей, переключение в чате

```
/модели          показать список
/модель 2        переключить по номеру
/модель быстро   переключить по названию
```

| # | модель | провайдер | скорость |
|---|---|---|---|
| 1 | `qwen/qwen3.8-27b` | Groq | 0,2–0,3 с |
| 2 | `openai/gpt-oss-120b` | Groq | 0,6–16 с |
| 3 | `nvidia/nemotron-3-super-120b-a12b:free` | OpenRouter | 0,7–2,5 с |
| 4 | `inclusionai/ling-3.1-flash` | OpenRouter | 1,6–3 с |
| 5 | `liquid/lfm-2.5-2.6b:free` | OpenRouter | ответит не всегда |

Первая — на каждый день: быстрая и свободно говорит по-русски.

### Ключи

Лежат в `bots/секреты/ключи-моделей.local.json`, файл вне git.
Сейчас там 8 ключей Groq, 9 OpenRouter и 7 Mistral: лимит
считается на ключ, поэтому бот чередует их и получает в восемь
раз больше возможностей, чем с одним.

Ключи — копия из `zagent/config/secrets.local.json`. Источник
правды — там; если ключи поменялись, обновить копию:

```powershell
.\.venv\Scripts\python.exe tmp\wire_providers.py
.\.venv\Scripts\python.exe tmp\upload_bots_secret.py
```

* отклик на имя: Ада, ада, АДА, Толя, Толян, Катя, катюх, Кет;
* молчание на «палата», «толяк», «кетоны»;

* арифметика, время и длина текста;
* команды настройки характера и выбора модели.

Свободный разговор — только через нейросеть.

## Ограничения тарифа

* **Одна консоль.** Три процесса не запустить — памяти не
  хватит. Поэтому `run_all.py` поднимает трёх ботов одним
  процессом с тремя потоками.
* **Ключ API не управляет консолью.** Отправка команды по ключу
  отвечает 405. Запускать — руками в браузере.
* **Фоновые задачи недоступны по API.** Боты живут только пока
  открыта консоль. Планировался «вечный» запуск через
  веб-приложение, но `wsgi.py` на сервере не заводится.

---

## Чего делать нельзя

* **Писать ключи в код или в репозиторий.** Токен в истории git
  остаётся навсегда: его отзывут только перевыпуском у
  @BotFather.
* **Писать ключи в команды консоли.** Они останутся в истории.
  Скрипт `запустить.sh` существует именно ради этого.
* **Править файлы прямо на сервере.** При выкладке пропадёт.
* **Править `bots/код/`, пока боты работают.** Закрой консоль
  сначала.
